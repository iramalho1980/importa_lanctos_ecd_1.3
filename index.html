Importar SPED ECD

Prepare seus lançamentosImportação inteligente para o fluxo contábil

Importe o arquivo original do SPED ECD (.txt) e, em seguida, realize o de-para para que os lançamentos sejam importados corretamente para o sistema.

Importante: informe os códigos reduzidos das contas analíticas do sistema Domínio.

Importar plano de contas do Domínio

Para continuar o mapeamento automático, acesse o sistema Domínio e exporte a relação de contas analíticas.

  1. Acesse o módulo Contabilidade;
  2. Abra o menu Relatórios > Cadastrais > Contas;
  3. Clique no ícone do disquete para salvar o relatório;
  4. Selecione o formato Planilha com cabeçalho e salve o arquivo;
  5. Na sequência, importe essa planilha nesta etapa.

O arquivo deve ser uma planilha Excel com cabeçalho para que as colunas de nome e código sejam identificadas corretamente.

    Para melhorar o mapeamento e a similaridade, informe a natureza das contas cujo primeiro nível não é 1 (Ativo) ou 2 (Passivo). Se houver divergência com o plano Domínio, o sistema exibirá um aviso e permitirá prosseguir mediante confirmação.
